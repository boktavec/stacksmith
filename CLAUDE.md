# StackSmith agent guidance

`AGENTS.md` is the single source of agent guidance for this repository. Read and follow it before working; it contains StackSmith's scope, planning/review workflow, security boundaries, and completion checks.

Use `docs/stacksmith-core-plan.md` for the product design and `docs/spec/features/` for feature-specific contracts. This project is also a Go and Terraform learning exercise: explain important concepts briefly as they arise, while keeping the implementation small and understandable.
